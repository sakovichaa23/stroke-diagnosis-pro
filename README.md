## 📋 О проекте

Специализированная медицинская система для высокоточной диагностики ишемического и геморрагического инсульта с использованием глубоких нейронных сетей. Система ориентирована на профессиональную работу с медицинским стандартом **DICOM** и потоковую обработку данных.

### ✨ Ключевые возможности

| Функция | Описание |
|---------|----------|
| **🏥 Клинический режим** | Анализ единичных КТ-снимков с точной локализацией поражения (полушарие, артериальный бассейн) и цветовой сегментацией |
| **🚀 Массовый поток** | Загрузка целых папок DICOM-файлов. Автоматическая обработка серии снимков за один клик |
| **📊 Аналитика** | Построение графиков тяжести патологий, распределения инсультов по полушариям и бассейнам |
| **📄 Отчеты** | Генерация PDF-протоколов с результатами, клиническими рекомендациями и DICOM-метаданными |
| **🔍 Фильтрация истории** | Сортировка по вердикту, полушарию, площади поражения, достоверности |
| **📁 Поддержка форматов** | DICOM |

### 🎯 Результаты диагностики

Система определяет:
- **Статус:** НОРМА / ИНСУЛЬТ
- **Тип:** Ишемия/Отек (HU < 50) или Кровь/Геморрагия (HU > 50)
- **Локализация:** Левое/Правое полушарие + бассейн (ПМА/СМА/ЗМА)
- **Площадь поражения:** в процентах от общей площади среза
- **Достоверность:** уверенность нейросети в процентах

## 🛠 Технологический стек

| Компонент | Технология |
|-----------|------------|
| **Фреймворк ИИ** | PyTorch, Segmentation Models PyTorch |
| **Архитектура** | U-Net с энкодером EfficientNet-B4 |
| **Медицинские данные** | pydicom (чтение и парсинг метаданных DICOM) |
| **Интерфейс** | Gradio (многовкладочная структура) |
| **База данных** | SQLite (хранение истории анализов) |
| **Визуализация** | Matplotlib, OpenCV |
| **Отчеты** | FPDF (генерация PDF) |

## 📁 Структура проекта

* **app.py** — Основной файл запуска (интерфейс Gradio)
* **main_logic.py** — Клинический и пакетный режимы обработки
* **config.py** — Константы и настройки
* **database.py** — Работа с SQLite (сохранение истории)
* **segmentation.py** — Нейросеть U‑Net + EfficientNet-B4
* **dicom_preprocessing.py** — Чтение DICOM и извлечение метаданных
* **diagnosis.py** — Анализ плотности HU, артериальные бассейны
* **report.py** — Генерация PDF-отчётов и графиков
* **stroke_model.pth** — Веса обученной модели
* **requirements.txt** — Список необходимых библиотек
* **README.md** — Документация

## 🚀 Как запустить

### Онлайн-демо:
👉 **[Открыть Stroke Diagnosis Pro на Hugging Face](https://asakovic75-stroke-diagnosis-pro.hf.space/)**

### Локально:
1. Клонируйте репозиторий:
```bash
git clone https://github.com/sakovichaa23/stroke-diagnosis-pro.git
cd stroke-diagnosis-pro
```
2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для Mac/Linux:
source venv/bin/activate
```
3. Установите зависимости:
```bash
pip install -r requirements.txt
```
4. Запустите программу:
```bash
python app.py
```
